誠品《2025年度閱讀報告》、博客來年度／月暢銷榜（民間長期追蹤「書市春秋」整理）、Readmoo 2025電子書年度榜、相關媒體報導。</p>

<h2>摘要</h2>
<p>2024年10月至2026年10月，台灣出版市場呈現「總量回穩、結構分化」的格局。文策院調查顯示，2024年紙本圖書出版端營業額138.18億元（年增3.84%）、市場端200.12億元（年增2.05%），終止2019–2023年連年下滑；但ISBN申請種數連年減少（2024年54,767種，年減4.48%），出版趨向精緻化與集中化。暢銷榜由商業理財與心理勵志長期主導（《原子習慣》連霸博客來榜79個月），漫畫／圖文書是網路通路最大宗（金石堂月榜漫畫占72%），翻譯書占比持續攀升（2024年店銷書翻譯占比53.65%，已過半）。Gen Z讀者成為成長動能（誠品新進會員近五成為Gen Z），紙電共存、AI製作有聲書爆發（年增289%）、台漫與華文作家國際授權發光，是本期最顯著的結構變化。</p>
<hr />
<h2>一、暢銷類型變化</h2>
<h3>1.1 商業理財、心理勵志：長期霸榜的基本盤</h3>
<ul>
<li>五個網路通路（博客來、金石堂、誠品、三民、MOMO）2024年第四季月暢銷榜中，「商業理財」皆為前五大類型；八個通路季銷售Top 50中，商業理財為各通路共同暢銷類型，其次為心理勵志（文策院，2024年第四季暨年度報告）。</li>
<li>長銷書高度集中於此二類：2019年出版的《原子習慣》連續四季橫跨8個通路暢銷，並連霸博客來心理勵志、商業理財雙榜79個月（至2025年底）；《蛤蟆先生去看心理師》（2022）連霸47個月、《被討厭的勇氣》（2014）在榜達129次、《我可能錯了》電子書連霸36個月（書市春秋追蹤，2025–2026）。</li>
<li>2024年跨通路暢銷新書亦以此二類為主：《張忠謀自傳》上下冊（2024/11出版即登8個通路Top 10）、《長期買進》（周冠男，8通路）、《蔡康永的情商課3》（8通路）、《納瓦爾寶典珍藏版》（2025年博客來總榜／商業理財新書冠軍）、《持續買進》《致富心態》。</li>
<li>供給面呼應需求：2024年商業理財新書出版種數1,473種，較2023年增加174種（文策院產業調查報告）；報告解讀與該年股市交易熱絡、大眾積極投入市場有關。</li>
</ul>
<h3>1.2 文學小說：出版量最大，但暢銷集中於話題作與經典</h3>
<ul>
<li>2024年文學小說新書出版量占全年18%，為各類型之冠（文策院季報）；主要通路上架種數2,648種，居第三（文策院產業調查報告）。</li>
<li>暢銷呈兩極化：一是話題新作，如《世界上最透明的故事》（2024/9，皇冠）橫跨8個通路暢銷、拿下2025年博客來文學小說年度冠軍與誠品翻譯文學TOP 1，續集《世界上最透明的故事2》2025年底接棒在榜；二是經典長銷，《百年孤寂（平裝典藏版）》連霸博客來文學小說榜96個月。</li>
<li>諾貝爾文學獎效應顯著：韓江《素食者》在2024年第四季橫跨6個通路暢銷。</li>
</ul>
<h3>1.3 漫畫／圖文書：網路通路最大宗，動畫化帶動原作</h3>
<ul>
<li>2024年漫畫／圖文書新書上架種數2,584種，較2023年增加235種，是成長最顯著的類型之一；文策院指出主因是國際串流平台改編動畫帶動原著漫畫閱讀需求。</li>
<li>通路分眾明顯：金石堂網路月榜漫畫占72%、輕小說11%；博客來月榜漫畫占38%為最大宗；2026年1月博客來總榜漫畫／圖文書占比36.57%，為增幅之冠（書市春秋）。</li>
<li>2024下半年通路暢銷漫畫：Q3《排球少年》、Q4《膽大黨》與《吉伊卡哇》（後者橫跨兩季多本暢銷）；誠品漫畫圖文書榜上「吉伊卡哇」曾佔據6席（誠品2025閱讀報告）。</li>
<li>BL／GL為漫畫新書內容元素前二名；金石堂2025年度百合漫畫榜多部作品首刷即完售；台灣原創百合小說自2020年起出版量倍數成長進入「爆發期」（Zenodo研究，2026）。</li>
</ul>
<h3>1.4 童書／青少年文學：出版量居次，通路依賴度高</h3>
<ul>
<li>2024年新書上架2,704種，居第二；MOMO購物網以童書／青少年文學為銷售主力；紀伊國屋季暢銷書中童書占13%。</li>
<li>長銷系列穩定：《神奇柑仔店17》《屁屁偵探讀本11》（2024/Q4跨5通路暢銷）、《如果歷史是一群喵》系列（第14集為年度四季暢銷唯一人文社科類；第15集拿下2025年博客來人文史地／社會科學新書冠軍）。</li>
<li>誠品觀察：童書明星角色透過大量授權合作（人偶見面會、玩教具）大受歡迎（2025閱讀報告）。</li>
</ul>
<h3>1.5 輕小說：出版微減，電子化程度最高</h3>
<ul>
<li>2024年紙本輕小說上架640種，較2023年減少67種；但電子書輕小說出版種數自2022年1,849種降至2024年1,066種，顯示整體供給收縮。</li>
<li>輕小說是紙電同步出版比例最高的類型之一（達70%以上）；台輕小說《特殊傳說III vol.09》（護玄）2024年第四季橫跨6個通路暢銷，顯示本土輕小說仍有市場。</li>
</ul>
<h3>1.6 其他類型消長</h3>
<ul>
<li>自然科普：2024年上架513種，較2023年大增182種（+55%），出版家數增加23家為各類最多；《我家附近的鳥鄰居》為2025年博客來自然科普新書冠軍。</li>
<li>宗教命理：上架951種（+117種），Q4出版量明顯提升，定價隨季度成長。</li>
<li>考試用書、國中小參考書：仍是出版種數最多的類型（考試用書2,712種居冠），但2024年分別減少189種、363種，廠商家數亦減少最多，呈現收縮。</li>
<li>電腦資訊：上架種數大減238種（572→334種），定價微降，是衰退最明顯的類型。</li>
</ul>
<p><strong>結論：</strong> 商業理財與心理勵志是橫跨實虛通路、長達數年的暢銷基本盤；漫畫／圖文書主導網路通路且受動畫化驅動成長；文學小說「出版量大、暢銷集中」；童書穩定；考試／參考書類供給收縮；自然科普與宗教命理逆勢成長。</p>
<hr />
<h2>二、新興主題</h2>
<h3>2.1 AI：從出版技術走向閱讀主題</h3>
<ul>
<li>產業面：文策院2024年產業調查首度專章調查AI應用，出版業者多用於「提升內容產製效率」與「數位教材生成」，部分出版社開始實驗AI生成圖書內容；AI製作有聲書是2024年有聲書種數暴增289%的主因之一。</li>
<li>主題面：AI相關書籍進入暢銷榜，如《台灣AI大未來》連續三個月在博客來電子書榜在榜（2025年底）；《黃仁勳傳》為2025年誠品／Readmoo商業理財暢銷書；但AI主題尚未形成如心理勵志般的長期書系，仍屬話題波段。</li>
</ul>
<h3>2.2 身心療癒：從心理勵志延伸至身心醫學與高敏感族群</h3>
<ul>
<li>心理勵志長銷書本質多為療癒取向（《蛤蟆先生去看心理師》《我可能錯了》《被討厭的勇氣》）；2024年《失控的焦慮世代》拿下博客來人文史地／社會科學雙料年度冠軍，反映青少年心理健康焦慮成為公共議題。</li>
<li>2025年新書：《你的人生，他們六個說了算！》拿下博客來心理勵志／電子書新書雙冠；《高敏感的你要這樣守護自己》（2025/4，世茂）等高敏感族（HSP）書籍進入市場；台大醫師張立人《終結腦疲勞！》結合職場心理學、正念與睡眠科學，瞄準上班族「腦疲勞」文明病。</li>
<li>醫療保健類《【實證醫學完整解析】糖尿病緩解心法》（2025/1）連續12個月在榜，顯示實證醫學×慢性病主題的穩定需求。</li>
</ul>
<h3>2.3 熟齡議題：五十歲世代的自我書寫</h3>
<ul>
<li>彭菊仙《五十歲後我出去一下》、沈春華《在歲月裡淘金，一閃一閃亮晶晶》進入2025年誠品暢銷榜（天下文化整理）；吳若權《捨得自己》亦屬熟齡自我關懷書寫。熟齡主題由資深媒體人／作家帶動，尚屬個別佳作，未形成大規模書系。</li>
</ul>
<h3>2.4 本土歷史與飲食文化：知性熱潮延續</h3>
<ul>
<li>《如果歷史是一群喵》系列橫跨2024–2025年持續暢銷（第14、15集皆為跨通路暢銷書）；《餐桌上的臺灣史》為2025年博客來飲食類年度冠軍（2024/6出版，在榜19個月），顯示以輕鬆形式包裝的本土文史、飲食文化書籍有穩定市場。</li>
</ul>
<h3>2.5 永續／地方創生：專業書有亮點，大眾書系未成形</h3>
<ul>
<li>《永續發展相關規範與實務（113年版）》因金管會規範要求，連續多季進入單一通路暢銷榜，屬專業／政府出版品的剛性需求，非大眾閱讀風潮。</li>
<li>地方創生主題未見進入各通路年度暢銷榜前列；相較之下，「台灣」為題的文學與文史書（如《臺灣漫遊錄》《餐桌上的臺灣史》）更具市場動能。</li>
</ul>
<p><strong>結論：</strong> 真正「冒出來」的新興動能是AI（技術應用先於主題書）、身心療癒的細分化（焦慮世代、高敏感、腦疲勞）與自然科普出版熱；熟齡、永續、地方創生多屬個別佳作或專業剛需，尚未形成可與心理勵志比肩的書系規模。</p>
<hr />
<h2>三、本土原創 vs 翻譯書</h2>
<h3>3.1 翻譯書占比連年攀升，店銷書已過半</h3>
<ul>
<li>文策院產業調查報告（圖23）：整體圖書翻譯占比自2021年34.92%逐年升至2024年43.68%；若排除考試／教科書等非店銷書，店銷書翻譯占比自2021年48.25%升至2024年53.65%，已超過一半，本土原創僅46.35%。</li>
<li>季報口徑（四通路新書）：2024年第四季新書30%為翻譯書；網路通路月暢銷榜圖書約四成為翻譯書；八通路季暢銷Top 50中45%為翻譯書；Kobo電子書榜圖書78%為翻譯書、Readmoo月榜67%為翻譯書。</li>
<li>漫畫翻譯依賴度極高：2024年第四季漫畫新書91%為翻譯（日漫為主）；漫畫業者營收96.83%來自國外作品，國內作品僅3.17%。</li>
</ul>
<h3>3.2 翻譯來源：日本近半且持續擴大</h3>
<ul>
<li>2024年翻譯書來源：日本48.44%（4,706種，2022年46.52%→逐年上升）、美國17.58%、中國11.60%、英國7.64%、韓國6.97%（文策院產業調查報告，圖24）。</li>
<li>日漫畫、輕小說、日系心理勵志與商業書是翻譯大宗；韓國文學（韓江《素食者》）、美國商業書（《原子習慣》《納瓦爾寶典》）亦具影響力。</li>
</ul>
<h3>3.3 本土作家異軍突起：國際獎項帶動版權輸出</h3>
<ul>
<li><strong>楊双子《臺灣漫遊錄》（春山出版）</strong>：2024年獲美國國家圖書獎翻譯文學大獎（台灣首位）、日本翻譯大賞、金鼎獎；2026年再獲國際布克獎（台灣文壇史上第一次）；售出13種語言版權，英文版登2025年誠品外文書暢銷TOP 1、Readmoo 2025電子書文學小說榜TOP 1。</li>
<li><strong>李佳穎《進烤箱的好日子》</strong>：睽違16年回歸文壇，獲企鵝藍燈書屋簽下全球英文版權，售出11國版權；為2025年博客來文學小說新書冠軍。</li>
<li><strong>黃山料</strong>：療癒系作家，登2025年誠品暢銷華文作家TOP 1，並同步進入香港、吉隆坡暢銷華文作家前10名。</li>
<li><strong>周冠男《長期買進》</strong>：本土財經學者著作，2024年橫跨8個通路暢銷，電子書連霸17–18個月，打破翻譯理財書壟斷。</li>
<li><strong>護玄《特殊傳說III》</strong>：本土輕小說2024年第四季橫跨6個通路暢銷。</li>
<li><strong>微疼《微詭畫事件簿》</strong>：台灣網路漫畫家作品，2024年連續兩季跨通路暢銷。</li>
<li>授權輸出面：台灣恐怖小說（如《筷》）、BL圖書在韓語、泰語地區受歡迎；《鬼地方》及奇幻、推理、社會寫實小說在韓國受關注；2025年首爾書展後臺韓交流更趨熱絡（文策院業者訪談）。</li>
</ul>
<p><strong>結論：</strong> 翻譯書占比連年上升、店銷書已過半，日本來源近半且持續擴大，是這兩年最明確的結構趨勢；但本土原創在文學（楊双子、李佳穎）、理財（周冠男）、輕小說、台漫等領域出現具國際版權實力的突破案例，呈現「量上翻譯擴張、質上本土發光」的並存格局。</p>
<hr />
<h2>四、通路與載體變化</h2>
<h3>4.1 實體書店：連鎖收縮、獨立書店轉向複合經營</h3>
<ul>
<li><strong>金石堂</strong>：全盛時期102間門市，目前僅剩19間（維基百科）；2025年10月至2026年8月間關閉中壢、台南南新、彰化光復、板橋文化、台南中山、高雄三多、屏東潮州、新店（33年）、中和環球（21年）等店，僅2026年8月於桃園大江購物中心開出新店。</li>
<li><strong>誠品</strong>逆勢展店：2025年出版品銷量930萬冊、年增近3%；新開台南獨棟大店、東港王船限定店、屏東恆春店，改裝松菸24小時書店，亞洲達51個據點；動漫祭帶動29歲以下購書會員成長118%（誠品2025閱讀報告）。</li>
<li><strong>書店營收結構</strong>（文策院2024年產業調查）：整體書店紙本出版品營收占53.46%、文創及衍生商品33.01%、餐飲3.48%（逐年成長）；單一獨立書店紙本占比53.97%（較2023年下降6.25個百分點），文創占32.56%，顯示獨立書店加速複合經營；文化幣占整體書店營收7.02%。</li>
<li>年營收低於500萬元的書店占67.62%（較2023年上升），產業呈現「大者展店、小者艱困」的兩極化。</li>
</ul>
<h3>4.2 網路書店：仍是主力，但實體占比回升</h3>
<ul>
<li>整體書店營收來自網路通路占46.19%、實體通路53.81%；文策院指出「在實體經濟恢復與書市活動活絡下，實體通路的營收占比超過網路通路」。</li>
<li>單一獨立書店網路營收占比自2023年7.26%明顯上升至2024年16.90%，反映獨立書店積極開拓線上銷售。</li>
<li>各網路通路定位分化：博客來圖書／漫畫均衡、具指標性；金石堂網路以漫畫（72%）、輕小說為主力；三民以考試用書、童書、人文社科見長；MOMO主攻童書；誠品線上藝術設計類獨強。</li>
</ul>
<h3>4.3 電子書：穩定成長，紙電共存成常態</h3>
<ul>
<li>2024年新書紙電皆出版比例42.04%（無論是否同步）；輕小說、漫畫／圖文書達70%以上；翻譯書59.98%高於本國書35.77%。</li>
<li>誠品電子書上市滿一年：用戶遍布五大洲，21–35歲占逾五成；同時購買紙電的會員購書量為僅購紙本者的2.2倍、金額高120%，顯示紙電互補而非替代。</li>
<li>數位平台營收結構：電子書占數位出版品營收72.14%、電子漫畫18.05%、電子雜誌9.81%、有聲書／影音書4.34%；訂閱制收入占41.38%（文策院2024年產業調查）。</li>
<li>彩色閱讀器帶動：81.82%平台業者認為帶動電子書讀者增加，70%認為促進漫畫／輕小說銷售成長。</li>
<li>公共借閱面：電子書借閱量連續維持1,800萬冊以上；文化部計次借閱3年成長2.3倍；出版業者普遍實施約6個月新書授權空窗期以保護新書銷售（BookManta，2025）。</li>
</ul>
<h3>4.4 有聲書：爆發性成長但品質隱憂</h3>
<ul>
<li>2024年有聲書ISBN申請1,201種，較2023年309種暴增288.67%；上架至博客來／Readmoo／鏡好聽共1,543種，年增129.96%（文策院產業調查報告）。</li>
<li>類型以人文社科（356種）、青少年與兒童（345種）、文學小說（280種）、商業理財（247種）為主；年增最多為商業理財與青少年兒童。</li>
<li>成長主因：一是出版社應用AI技術製作有聲書，大幅降低產製門檻；二是部分出版社大量製作「濃縮中國圖書內容」之有聲書，帶動種數膨脹，品質與版權爭議值得關注。</li>
</ul>
<p><strong>結論：</strong> 連鎖實體書店持續收縮（金石堂剩19間），但誠品以體驗與展店逆勢成長、獨立書店轉向文創餐飲複合經營；網路仍是主力通路，惟實體營收占比回升；電子書穩定成長且與紙本互補，有聲書則因AI產製而爆發性成長，惟內容品質參差。</p>
<hr />
<h2>五、產品形態趨勢</h2>
<h3>5.1 定價：平均定價持平，類型分化</h3>
<ul>
<li>圖書平均定價2024年為425元，與2023年（424元）大抵持平（CPI年增2.18%）；2021年曾達448元高點後回落（文策院產業調查報告）。</li>
<li>新書單書定價中位數2024年四季維持380–390元，整體價格帶穩定（文策院季報）。</li>
<li>類型分化：藝術設計（平均619元）、自然科普（617元）、醫療保健（496元）調漲明顯；商業理財（461→436元）、宗教命理、考試用書等調降。平均折扣維持8.4折，翻譯書（8.2折）折扣深於本國書（8.5折），價格競爭較劇烈。</li>
</ul>
<h3>5.2 裝幀設計：紙本書以「體驗設計」突圍</h3>
<ul>
<li>《世界上最透明的故事》將推理線索融入排版設計，「只有紙本書能體驗」，成為2025年誠品翻譯文學TOP 1與博客來文學小說年度冠軍，是「載體即內容」的代表案例；文策院報告亦引此書說明部分類型不適合轉製電子書。</li>
<li>經典文學限定版風潮：《傲慢與偏見》珍．奧斯汀250歲冥誕珍藏紀念版、《追憶似水年華》全球首套繁體中文全本（7冊）、《百年孤寂》平裝典藏版長銷，顯示收藏型裝幀是紙本書差異化策略。</li>
<li>特殊版本普及：2024年第四季6%圖書新書、15%漫畫新書推出首刷／特別書衣／限量版等特殊版本；金石堂百合漫畫榜多部作品以「首刷限定版」完售，顯示限量策略有效刺激預購。</li>
</ul>
<h3>5.3 套書：長銷與收藏的主力形式</h3>
<ul>
<li>Readmoo 2025電子書文學小說榜Top 3為《哈利波特》繁中電子書套書；《張忠謀自傳》上下冊合售、《納瓦爾寶典珍藏版》、史蒂文．巴列特限量套書（耀黑燙金版）皆為年度暢銷書，顯示套書／珍藏版是拉高客單價的有效形式。</li>
</ul>
<h3>5.4 IP跨界經營：影視改編熱，漫畫改編斷鏈</h3>
<ul>
<li>影視改編投入顯著增加：文化部影視局2025年訂定《劇集劇本開發補助要點》，「我國原創作品跨IP改編」列優先補助（單案最高300萬元）；文策院與鏡文學合資3.1億元成立「鏡好看」，五年開發十部影視作品；成功案例有《八尺門的辯護人》《俗女養成記》（vocus產業分析，2026）。</li>
<li>出版業者對外授權中，「漫畫小說相互改編」「改編影視／動畫／遊戲」占比增加；內容訂閱服務授權占6.02%（較上年+2.49個百分點）（文策院產業調查報告）。</li>
<li>反差：台灣小說改編漫畫產業鏈斷裂（漫畫首刷1,000本完售即屬不錯，市場規模不足以支撐產業鏈）；漫畫IP授權以原稿授權為主（國外54.55%）。</li>
<li>童書IP授權活躍：童書明星角色透過人偶見面會、玩教具等授權合作創造衍生收益（誠品2025閱讀報告）；吉伊卡哇等療癒系IP橫跨圖書與周邊。</li>
</ul>
<p><strong>結論：</strong> 定價整體持平但類型分化；紙本書以體驗式裝幀（排版即推理）、限定珍藏版與特殊版本應對電子化；套書／珍藏版支撐客單價；IP經營重心在影視改編（政策與資金加持）與童書角色授權，漫畫改編則因市場規模受限而斷鏈。</p>
<hr />
<h2>六、出版社策略</h2>
<h3>6.1 行銷全面轉向線上與社群</h3>
<ul>
<li>2024年出版社行銷資源投放前三名皆為網路管道：自家網站／社群媒體（23.36%）、網路書店與數位平台首頁廣告（15.41%）、網路通路圖書策展（11.97%），且占比皆較上年增加（文策院產業調查報告）。</li>
<li>質性訪談顯示業者加碼社群短影音、遊戲化行銷、金句分享、說書頻道；漫畫業者反映行銷公關廣告支出占比近兩年增加，主因是銷售仰賴社群媒體與通路平台推薦曝光。</li>
<li>數位轉型最大挑戰為「人力有限」（58.13%），中小型出版社（10人以下占72.29%）資源尤為吃緊。</li>
</ul>
<h3>6.2 擁抱AI，但聚焦效率而非取代創作</h3>
<ul>
<li>AI應用以提升內容產製效率、數位教材生成為主，部分出版社實驗AI生成圖書內容、AI製作有聲書、AI規劃行銷計畫（文策院產業調查報告）。</li>
<li>隱憂並存：大量AI產出電子書意圖洗刷政府補助，引發產業疑慮（BookManta，2025）。</li>
</ul>
<h3>6.3 紙電同步與訂閱制並進</h3>
<ul>
<li>2024年新書紙電皆出版達42.04%，誠品預言「紙電同步出版」將成常態；但業者仍審慎評估書籍類型適配性（如推理小說、旅遊工具書以紙本為主）。</li>
<li>數位平台訂閱制收入占41.38%，受重視度自2023年8.67%升至2024年12.82%；出版社將出版兩年以上舊書放入訂閱書庫以延續曝光（文策院產業調查報告）。</li>
</ul>
<h3>6.4 版權輸出與IP多元開發</h3>
<ul>
<li>38.53%有授權業務的出版社將版權授權至海外，語系以繁中（31.67%）、簡中（30.56%）、英語（10.0%）為主；韓語、泰語市場對台灣恐怖、BL、奇幻推理小說需求上升。</li>
<li>授權類型多元化：有聲書／影音書、內容訂閱、漫畫小說相互改編、影視／動畫／遊戲改編占比皆增加；授權收入成長的業者多為手作生活、幼兒／青少年讀物、漫畫／輕小說出版商。</li>
</ul>
<h3>6.5 體驗行銷與年輕客群經營</h3>
<ul>
<li>誠品以動漫祭（17間主題IP店）、「月讀一冊」77折（年吸50萬人次）、書籤蒐集熱潮、金屬徽章會員制等方式深化讀者連結，帶動29歲以下會員成長118%。</li>
<li>台北國際書展2025：門票銷售年增28%、成年禮金抵用逾1,500萬元（+20%）、57萬人次參觀、版權交流2,031桌次創新高，61.32%參展業者認為書展助益為增加圖書銷售額。</li>
</ul>
<p><strong>結論：</strong> 出版社策略可歸納為四軸：行銷線上化（社群＋通路策展）、AI提效（有聲書、內容產製）、紙電同步＋訂閱制延續長尾、版權輸出與IP多元授權；在人力與資金普遍受限下，資源集中投向具改編潛力與社群話題的書種。</p>
